ЛОКАЛЬНЫЙ ПЕРЕВОДЧИК (НЕОБЯЗАТЕЛЬНО)

Проверка ARB и HTML работают без модели, на стандартном Python 3.10+.
Веса и .venv не загружаются в Git. Чтобы включить перевод на другом компьютере,
выполните из папки проекта (для модели рекомендуется Python 3.11 или 3.12):

python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-ai.txt
.venv\Scripts\python.exe setup_ai.py

Для установки нужен интернет. Затем start_project.cmd использует .venv и локальную
модель. По умолчанию генерируется до 12 новых строк с сигналами за запуск.
Чтобы обработать больше: start_project.cmd --ai-limit 500
Модель пропускает фрагменты с переменными и разметкой; такие строки проверяются
правилами, а перевод и игровой смысл подтверждаются человеком.

Модель: deepvk/kazRush-ru-kk, лицензия Apache 2.0.
Смысловая точность на игровых данных не подтверждена независимой оценкой.
Все новые варианты остаются черновиками до человеческого подтверждения.
