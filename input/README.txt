КАК ПРОВЕРИТЬ СВОИ ДАННЫЕ

1. Положите в эту папку два файла:
   intl_ru.arb — русский оригинал;
   intl_kk.arb — текущий казахский перевод.
   Если внутри есть @@locale: ru и kk, имена могут быть другими.
   На каждый язык должен быть только один ARB-файл.

2. При необходимости положите сюда:
   glossary.csv — глоссарий с колонками ru,kk;
   corrections.csv — выбранные исправления, колонки:
     key,translation,reviewed_by_human,comment
     reviewed_by_human=true — человек действительно проверил;
     false — черновик. Черновики будут явно отмечены в итоговом ARB.
   proposals.json — необязательные предложения в формате:
     {"ключ": ["первый вариант", "второй вариант", "третий вариант"]}

3. Дважды нажмите start_project.cmd в родительской папке.

4. Откроется result/index.html — общая таблица всех строк,
   найденные проблемы, исходный и итоговый перевод, предложения ИИ.
   result/all_data.json содержит все данные таблицы.
   result/issues.json содержит найденные сигналы.
   result/intl_kk_draft.arb содержит черновик: выбранные правки и первые
   технически корректные предложения ИИ. Человек еще должен проверить смысл.
   result/intl_kk_fixed.arb содержит только подтвержденные человеком правки.
   result/audit.json — проверка подтвержденного файла;
   result/draft_audit.json — проверка черновика.

Входные файлы в input не меняются. Повторный запуск обновляет result.
Для подтверждения скопируйте result/selected_corrections.csv в input/corrections.csv,
проверьте translation и поставьте reviewed_by_human=true только у проверенных строк.
Повторите запуск .cmd: подтвержденные строки попадут в intl_kk_fixed.arb.
Без подтвержденных исправлений intl_kk_fixed.arb совпадает со входным.
Предложения модели сами по себе не считаются одобренным переводом.
Загруженные ранее предложения ИИ доступны только для совпадающих строк.
Для новых текстов запускается локальный ИИ, максимум 12 строк за запуск.
Для другого лимита: start_project.cmd --ai-limit 50
Без запуска ИИ: start_project.cmd --ai-limit 0
Смысл и игровой сленг во всех вариантах проверяет человек.
