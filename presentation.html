КОНТУР B↗

Варианты исправления

Как сохранить смысл на казахском?

  • Локальные kazRush, NLLB и Qwen.
  • До трёх вариантов, если генератор смог их подготовить.
  • Словарь игровых терминов, контекст и проверка переменных.
Естественность оценивают носители
Исходные переводы→Решение носителя→Проверенные примеры→Ошибки для обучения→Проверка на новых данных

Обычная проверка и сборка результатов уже объединены в один запуск. Обучение детектора выполняется отдельно. Переводчики используют готовые модели. Их дообучение и надёжная работа с идиомами — следующие этапы.

01 / ПРЕЗЕНТАЦИЯ

Просто посмотреть

Откройте presentation.html в браузере или дважды нажмите open_project.cmd в Windows.

Python и интернет не нужны.
02 / СВОИ ДАННЫЕ

Проверить переводы

Положите intl_ru.arb и intl_kk.arb в input. Нужен Python 3.10+.

.\start_project.cmd --ai-limit 0

В Windows откроется result/index.html. В macOS/Linux: python3 workflow.py --ai-limit 0, затем откройте отчёт сами.

03 / ИИ-ПРЕДЛОЖЕНИЯ

Подключить переводчик

Установите локальную модель по INSTALL_AI.txt, затем запустите start_project.cmd.

Windows · до 12 новых строк за запуск.

Интернет нужен для установки. Предложения остаются черновиками.

Как принять исправления?

Откройте result/selected_corrections.csv → проверьте перевод → поставьте reviewed_by_human=true у одобренных строк → сохраните как input/corrections.csv → повторите запуск.

Одобренные изменения попадут в intl_kk_fixed.arb. Остальные предложения останутся в черновике.
