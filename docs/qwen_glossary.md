# Локальный переводчик с игровым глоссарием

## Что подготовлено

- Из 5 479 русских строк ARB извлечены 88 действительно встречающихся игровых терминов.
- [Читаемый глоссарий](../private/game_glossary_review.md) показывает черновой казахский вариант, альтернативы, частоту и неоднозначность.
- [CSV с контекстом](../private/game_glossary_candidates.csv) содержит примеры на русском, английском и текущем казахском. Текущий казахский может содержать ошибки кейса.
- Локальная модель [ISSAI Qwen3.5-4B-Kazakh](https://huggingface.co/issai/Qwen3.5-4B-Kazakh) запущена из [GGUF Q4_K_M](https://huggingface.co/mradermacher/Qwen3.5-4B-Kazakh-GGUF) через `llama.cpp`. Обе модели и данные организатора исключены из Git.
- `qwen_glossary_proposals.py` отправляет модели исходную строку, английский контекст и подходящие термины, затем отклоняет ответ, если он изменил плейсхолдеры, HTML-теги или числа.

Все 88 терминов пока имеют `reviewed_by_human=false`. Использование чернового глоссария допускается только для **непроверенных предложений**; это не эталон и не дообучение весов.

## Как утвердить термины без Excel

Прочитайте `private/game_glossary_review.md`. Для выбранных терминов в `private/game_glossary_candidates.csv` заполните `approved_kk` и поставьте `reviewed_by_human=true`. Если термин зависит от контекста, оставьте `use_for_ranking=false`: модель не будет навязывать его каждой строке. Можно также прислать решения в чате, и Codex внесёт их в файл.

## Повторный локальный запуск

Из корня проекта:

```powershell
python run_qwen_glossary.py --out private/qwen_after_approval.csv
```

Команда сама запускает локальную модель, переводит строки из `corrections.csv` и останавливает сервер. Она использует только человечески утверждённые термины. Чтобы **экспериментально** использовать черновые термины:

```powershell
python run_qwen_glossary.py --include-drafts --out private/qwen_glossary_candidates_v3.csv
```

Результат — отдельный CSV с предложениями и предупреждениями, без изменений ARB и без автоматических отметок человеческой проверки. Полное дообучение модели имеет смысл после получения набора утверждённых предложений в контексте. Изолированный список терминов для этого недостаточен.

Первый полный прогон с черновым глоссарием записан в `private/qwen_glossary_candidates_v3.csv`: **139** строк, из них **135** прошли техническую проверку структуры, **4** отклонены. В **81** строке модель получила хотя бы один термин. Эти числа не измеряют точность перевода. В пробах встречались смысловые ошибки, например неудачный перевод кнопки «Отмена», поэтому все предложения остаются непроверенными.

## Проверенные вручную пробы

С указанным в запросе термином модель ответила:

| Русский | Термин в запросе | Черновой ответ |
|---|---|---|
| Возможный выигрыш | выигрыш = ұтыс | Мүмкін ұтыс |
| Побед в турнирах | турнир = турнир; победа = жеңіс | Турнирлердегі жеңістер |
| Поздравляем, `{name}`! Вы получили `{count}` наград. | награда = сыйлық | Құттықтаймыз, `{name}`! Сіз `{count}` сыйлық алдыңыз. |

Проверка трёх примеров не измеряет общую точность и не заменяет оценку носителей.
